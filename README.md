# LEGION PRO BOT — تطبيق أندرويد
التطبيق واجهة (WebView) تفتح لوحة التحكم (app.py) المشغّلة على سيرفرك. البوت نفسه يبقى شغّالًا على السيرفر.

## بناء الـAPK (مجانًا على GitHub)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد (بما فيه مجلد .github).
2. افتح تبويب Actions ← Build APK ← Run workflow (يشتغل تلقائيًا مع كل رفع).
3. بعد دقائق نزّل الملف app-debug.apk من Artifacts ← LegionBot-apk وثبّته على الهاتف (اسمح بالتثبيت من مصدر غير معروف).
4. أول تشغيل: اكتب رابط السيرفر (مثال http://IP:5000). ⋮ ← تغيير رابط السيرفر لتعديله.
